## RF 2.4 GHz Signal Jammer 📡

An experimental Wireless Security project built with Arduino Nano and NRF24L01 (PA/LNA). This system is designed for RF testing and signal disruption simulation within the 2.4 GHz spectrum by transmitting a constant carrier wave across channels 0 to 79.

### Features
* 📡 **Wide-Band Disruption**: Scans and transmits continuous carrier waves across 80 different RF channels.
* ⚡ **High Power Output**: Utilizes the `RF24_PA_MAX` power amplifier level for enhanced test range.
* 🔋 **Portable Design**: Powered by a compact Lithium-Polymer (LiPo) battery system for mobile hardware testing.

## เครื่องตัดสัญญาณวิทยุ 2.4 GHz 📡

โปรเจกต์เชิงทดลองด้านความปลอดภัยไร้สายและการทดสอบคลื่นวิทยุ พัฒนาโดยใช้บอร์ด Arduino Nano ร่วมกับโมดูล NRF24L01 (PA/LNA) ระบบนี้ทำงานโดยการยิงคลื่นพาหะต่อเนื่อง (Constant Carrier) กวาดช่องสัญญาณตั้งแต่ช่อง 0 ถึง 79 เพื่อจำลองการบล็อกหรือรบกวนสัญญาณในย่านความถี่ 2.4 GHz

### ฟีเจอร์เด่น
* 📡 **รบกวนสัญญาณคลื่นความถี่กว้าง**: วนลูปสแกนและส่งสัญญาณคลื่นพาหะต่อเนื่องครอบคลุม 80 ช่องสัญญาณ
* ⚡ **กำลังส่งระดับสูงสุด**: เปิดใช้งานโหมด `RF24_PA_MAX` ควบคู่กับเสาอากาศขยายสัญญาณข้างนอกเพื่อขอบเขตการทดสอบที่กว้างขึ้น
* 🔋 **ระบบฮาร์ดแวร์พกพา**: ออกแบบวงจรรองรับพลังงานจากแบตเตอรี่ LiPo สำหรับนำไปใช้ทดสอบในพื้นที่จำลองต่างๆ
